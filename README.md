# Capstone Project 2 – Analisis Penjualan SaaS

Proyek ini merupakan bagian dari program pembelajaran data analysis yang berfokus pada pemahaman performa penjualan perusahaan berbasis SaaS. 
Analisis dilakukan menggunakan Jupyter Notebook.

Tujuan Proyek
- Menganalisis total profit pada setiap produk
- Mengindentifikasi profit dari setiap subregion
- Mengidentifikasi produk mana yang membuat rata-rata profit dari subregion merugi
- Mengidentifikasi apakah discount dapat mempengaruhi profit
